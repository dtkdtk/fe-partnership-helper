# FE Partnership Helper

**Discord-бот для контроля над партнёрствами на вашем сервере.**

> Если не знаете, что такое партнёрство в СНГ-сегменте Discord, значит вам этот бот не нужен.

> [!CAUTION]
> Early Access release — версия "Ранний доступ". В скором времени (по плану: конец января 2026)
> планируется выпустить полноценную версию. Ещё позже — многопользовательскую (не self-hosted).

Возможности:
- Подсчёт партнёрств, в том числе за период оффлайна бота (боту не страшны отключения) **и за всё время существования сервера** (подсчёт старых партнёрств)
- Статистика по кол-ву партнёрств у конкретных сотрудников и у всего отдела в целом (включая диаграмму-картинку)
- Проверка соблюдения условий партнёрства, доступных боту (валидность ссылки-приглашения, кол-во участников, кулдаун)
- Можно установить условие "сервер может публиковаться только 1 раз в день" со сбросом в 00:00 по произвольному часовому поясу (например, МСК)
- Чёрный список вашего сервера
- Привязка партнёра к тексту, отслеживание партнёров и оповещение об их выходах.
- Оповещения партнёра об успешном партнёрстве со списком его серверов.
- Простая поверхностная кастомизация (изменение цветов эмбедов, картинок, эмодзи, некоторых фрагментов текста).

Бот создан [@dtkdtk](https://github.com/dtkdtk) (DS: `@dtkdtk0`) для проекта [『FE』Federal Empire](https://discord.gg/vGVTAYS8vm). Эта версия предназначается **для одного сервера**, и использовать этого бота на нескольких вы просто не сможете. Автор надеется, что вы самостоятельно развернёте этого бота на своём хостинге и будете пользоваться его трудом в своё удовольствие.

Если вам пригодился этот код, и он сделал ваш сервер лучше, — пожалуйста, поставьте ⭐ звёздочку этому репозиторию, если у вас есть аккаунт в GitHub.

## Ставим платформу NodeJS

Этот бот работает на платформе NodeJS, и вы должны установить её на свой компьютер, чтобы запустить бота.

Скачать её можно здесь: https://nodejs.org/en/download . Нас интересует второй способ скачивания: `Or get a prebuilt Node.js`.
Скачиваем, устанавливаем как любую другую программу, перезагружаем ПК.

Далее, открываем командную строку (поищите в интернете, как это сделать), и проверяем, что у нас всё успешно установлено. Нужно вписать 2 команды и проверить, что они выполняются успешно:

```sh
node -v
npm -v
```

Они должны выдать их версии (что-то типо этого; цифры могут немного не совпадать):

```sh
v24.1.0
11.6.4
```

Если выдаёт какую-то ошибку, добро пожаловать в гугл. Разберитесь сами, это несложно.

# Немного о конфигурации бота (файл `.env`)

В файле присутствуют понятные комментарии. Стоит лишь прояснить "права ролей".


## Права ролей

Нужно настроить права (в боте) каждой из ролей.

Чтобы дать роли какие-либо права, нужно добавить в конфиг переменную вида...:
```ini
ROLE_ЗдесьАйди_PERMISSIONS = ЗдесьПрава
```
, где (ну логично же), `ЗдесьАйди` это ID роли, а `ЗдесьПрава` это список прав через запятую.

Права:
- `партнёрство` :: публиковать партнёрства
- `смотреть_чужую_стату` :: смотреть чужую статистику через `/био-делегата`
- `смотреть_стату_отдела` :: смотреть статистику отдела через `/стата-делегации`
- `управлять_партнёрством` :: изменять партнёра любого сервера через `/редактировать-партнёрство`, а также возможность обходить обязательные условия партнёрства. Обычно данное право также сопровождается правом управлять сообщениями в канале партнёрств.
- `управлять_чс` :: добавлять/удалять сервера из ЧС через `/редактировать-партнёрство`
- `админ` :: все нижеперечисленные права, а также права на все команды админа/разработчика. Этот уровень прав также имеют участники с правом Администратора.

Пример настройки прав:
```ini
ROLE_1338111583955456092_PERMISSIONS = админ
ROLE_1338110939974860880_PERMISSIONS = управлять_чс, управлять_партнёрством, смотреть_стату_отдела, смотреть_чужую_стату, партнёрство
ROLE_1338110006775513148_PERMISSIONS = управлять_партнёрством, смотреть_стату_отдела, смотреть_чужую_стату партнёрство
ROLE_1338110149352489044_PERMISSIONS = партнёрство
```


## Файл `bot-resources.json`

Здесь лежат все "ресурсы", используемые ботом для оформления его ответов / сообщений.
Обычно не требуется никаких настроек там. Однако, если хотите кастомизировать бота под свой проект, всегда пожалуйста.

Если удаляете оттуда рекламу, будьте добры поставить ⭐ этому репозиторию на Гитхабе.

Никаких объяснений, никакой документации к этому файлу не прилагается. По названиям полей понятно, за что они отвечают.
Если что, это файл формата JSON, и он отличается от вашего .env, а ещё тут более строгие требования к оформлению.
Если бот по непонятным причинам крашится после изменений в этом файле, проверьте соответствие формату JSON (посмотрите сами, погуглите, используйте ИИ).
Вдруг вы кавычки где-нибудь не закрыли. Такое бывает.

### Насчёт `button_icons`

В качестве значения принимается любой Unicode-эмодзи (например, 😀). Discord-коды НЕ принимаются (такие как `:smile:`, например);
кроме кодов **кастомных** эмодзи (именно эмодзи вашего сервера, например: `<:MyEmoji:128830189374873232>`).



# Немного о том, как работает бот

## Учёт партнёрств

Бот автоматически проверяет партнёрства в канале, указанном в конфиге (параметр `PARTNERSHIPS_CHANNEL_ID`). Проверяются следующие условия:
- Действительность ссылки-приглашения
- Является ли ссылка-приглашение временной?
- Количество участников (параметр `REQUIREMENT_MINIMAL_MEMBERS`, необяз.)
- Публиковался ли текст сегодня? (параметр `REQUIREMENT_ONCE_PER_DAY`, необяз.; можно настроить часовой пояс параметром `TIMEZONE_UTC_OFFSET`)
- Не добавлен ли сервер в ЧС

Если этот текст не проходит по условиям, бот упоминает делегата и просит удалить это партнёрство (с указанием причины) **в течение 3 минут**. Если делегат не удаляет этот текст самостоятельно, то его удаляет бот, отправляя уведомление в ЛС делегату (или в стафф-чат, если ЛС закрыто; *настроить стафф-чат можно параметром `STAFF_CHANNEL_ID`*).

Если у делегата есть право `админ` (или `управлять_партнёрством`), он может проигнорировать несоблюдение обязательных условий, нажав на кнопку `"Игнорировать"` под меню с ошибкой.

Следующие условия можно сделать *мягкими* (необязательными, но рекомендуемыми), через следующие параметры (установив значение `TRUE` - мягко, `FALSE` - обяз):
- Ссылка постоянная : `SOFT_REQ_PERMANENT_INVITE` (по умолчанию `TRUE`)
- Количество участников : `SOFT_REQ_MINIMAL_MEMBERS` (по умолчанию `FALSE`)
- Текст не публиковался сегодня : `SOFT_REQ_ONCE_PER_DAY` (по умолчанию `FALSE`)

При их несоблюдении текст НЕ удаляется, но в меню под ним будет предупреждение о несоблюдении мягких условий.

Если текст не проходит по любым условиям (и обязательным, и мягким), то меню под текстом будет с упоминанием делегата (чтобы тот обратил внимание). Иначе — без.

Если бот был оффлайн, то при его восстановлении он проверит **последние 100 непроверенных партнёрств** и удалит те из них, которые не проходят по условиям (разумеется, отправив уведомления в ЛС делегатам).

Счётчик партнёрств учитывает удаление партнёрств. Когда партнёрство удаляется самим делегатом / админом, счётчик партнёрств делегата уменьшается на 1.


## Меню под партнёрством

Когда партнёрство публикуется, бот может ответить на него либо ошибкой (с указанием её причины), либо меню сервера. В этом меню будет основная информация о сервере (название, ID, кол-во участников, аватарка).

..а также, в этом меню можно **назначить (привязать) партнёра** (если он на сервере). Здесь есть правило: **партнёр должен быть привязан ко всем его текстам**. Если к тексту уже привязан партнёр, это всё равно не мешает привязать нового.


## Оповещения партнёров в ЛС

Партнёрам приходят оповещения об успешном заключении партнёрства, с указанием всех их серверов.

Если у партнёра несколько серверов, то оповещения **группируются**. Без разницы, в каком порядке делегат публикует тексты и привязывает партнёра, важно, чтобы он делал это достаточно быстро и между каждыми привязками партнёра было не больше **30 секунд** (*это можно переопределить через параметр `PARTNER_ALERTS_BATCH_DURATION`*).


## Удаление старых текстов

Если не указано иного, старые тексты серверов удаляются (чтобы не засорять канал партнёрств), как только публикуется новый текст. Это значит, что в канале партнёрств будет висеть только один текст каждого сервера — самый актуальный (то есть последний опубликованный).

Однако, бот просматривает только последние 100 сообщений в канале, поэтому если старый текст где-то затерялся, он не будет удалён.

Эту функцию можно отключить, установив параметр `DELETE_OLD_TEXTS` на `FALSE` (по умолчанию / если не указан, то он `TRUE`).


## Первоначальное (полноценное) сканирование

Когда бот запускается впервые, он полностью сканирует весь ваш канал партнёрств, собирает статистику делегатов и удаляет оффтоп (включая сообщения от других ботов). Это действие абсолютно фоновое, оно не влияет на поведение бота.

Если установить параметр `GENERAL_SCAN_DELETE_UNFETCHED` на `TRUE`, бот будет удалять ещё и все сообщения с недействительными ссылками.

Сканирование устойчиво к перезагрузкам бота; можете смело останавливать / перезагружать бота в это время.


## Изменение / просмотр данных партнёрства; занесение в ЧС

Можно изменить данные партнёрства (в данный момент только партнёра, представляющего этот сервер) или просмотреть последние данные о сервере (название, кол-во участников, ID), с помощью команды `/редактировать-партнёрство <цель>`

Для этого нужно иметь ссылку-приглашение на сервер или ID этого сервера (и указать их в "цели"). Также, с этим сервером должно быть заключено партнёрство.

Через эту же команду можно занести указанный сервер в чёрный список (ЧС), чтобы с ним нельзя было заключить партнёрство. Если у вас есть право на занесение в ЧС, у вас будет кнопка в меню редактирования партнёрства.


## Статистика делегата и всего отдела

Есть 2 команды для просмотра статистики:
- `/био-делегата [юзер]` :: просмотр своей статистики (если не указан юзер), или статистики указанного делегата (если у вас есть на это право).
- `/стата-делегации` :: просмотр статистики всего отдела (сумма статистик всех делегатов). Только если у вас есть на это право.

В статистиках есть лежачий график, помогающий визуально проанализировать изменение количества партнёрств.


## Кастомизация бота на свой вкус

Если вы хотите поменять какие-либо эмодзи в боте, цвета, картинки, футеры, — можете открыть файл `bot-resources.json` и подредактировать там значения.
